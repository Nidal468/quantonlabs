==================================================
NEXT.JS FEATURES
==================================================

The AI should fully utilize modern Next.js features:

- App Router
- Route Handlers
- Server Components
- Client Components
- Server Actions
- Dynamic Routes
- Middleware
- Metadata API
- Streaming
- Suspense
- Error Boundaries
- Loading UI

==================================================
GENERAL RULES
==================================================

- Prefer Server Components whenever possible.
- Only use Client Components when interactivity is required.
- Keep components reusable.
- Write fully typed TypeScript.
- Follow modern React best practices.
- Keep code modular and scalable.
- Avoid unnecessary dependencies.
- Optimize for performance.
- Lazy load heavy components.
- Use image optimization.
- Keep bundle size small.
- Follow accessibility (ARIA) best practices.

==================================================
STRICTLY NOT ALLOWED
==================================================

Do NOT introduce:

- Prisma
- Drizzle ORM
- PostgreSQL
- MySQL
- SQLite
- Firebase Database
- Firestore
- Supabase Database
- PlanetScale
- Neon
- Turso
- Any SQL database
- Any ORM that replaces MongoDB
- Deprecated React libraries
- Outdated Next.js APIs

==================================================
FINAL RULE
==================================================

Unless explicitly instructed otherwise, the AI should assume this technology stack:

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- MongoDB
- Mongoose
- Framer Motion

No other database may be used under any circumstance.
