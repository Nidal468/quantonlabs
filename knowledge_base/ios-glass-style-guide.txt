================================================================================
1. DESIGN PHILOSOPHY
================================================================================

iOS glassmorphism is characterized by:
- Frosted glass/blur effects that let background content show through
- Semi-transparent surfaces with subtle borders
- Soft shadows creating depth and layering
- Clean, minimal typography (SF Pro Display / Inter / system fonts)
- Vibrant gradients behind glass elements
- Rounded corners (typically 12px-20px)
- Light, airy feel with plenty of whitespace

Key Principles:
- Layering: Use multiple translucent layers to create depth
- Blur: Background blur is the signature effect
- Subtlety: Borders and shadows should be gentle, not harsh
- Consistency: Maintain uniform blur values and opacity across components

================================================================================
2. CORE CSS PROPERTIES
================================================================================

The essential CSS properties for iOS glass effects:

/* Basic Glass Container */
.glass {
    background: rgba(255, 255, 255, 0.7);
    backdrop-filter: blur(20px);
    -webkit-backdrop-filter: blur(20px); /* Safari support */
    border: 1px solid rgba(255, 255, 255, 0.3);
    border-radius: 16px;
    box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
}

/* Key Properties Explained:

1. backdrop-filter: blur(Xpx)
   - Creates the frosted glass effect
   - Typical values: 10px - 40px
   - Higher values = more blur = more privacy
   
2. background: rgba(R, G, B, alpha)
   - Semi-transparent background
   - Alpha typically 0.4 - 0.8
   - Lower alpha = more transparent
   
3. border: 1px solid rgba(255, 255, 255, 0.2-0.5)
   - Subtle white border for definition
   - Creates the "edge" of the glass
   
4. box-shadow
   - Soft, diffused shadows
   - Use low opacity (0.05 - 0.15)
   - Multiple shadows for depth
*/

================================================================================
7. BEST PRACTICES
================================================================================

PERFORMANCE:
- backdrop-filter is GPU-intensive; use sparingly
- Avoid stacking multiple blur layers
- Use will-change: backdrop-filter for animated elements
- Consider fallbacks for older browsers
- Test on mobile devices for performance

ACCESSIBILITY:
- Ensure sufficient contrast ratio (4.5:1 for text)
- Don't rely solely on blur for content separation
- Provide solid background fallbacks when needed
- Test with reduced motion preferences:
  
  @media (prefers-reduced-motion: reduce) {
      .glass-animated {
          transition: none;
          animation: none;
      }
  }

DESIGN TIPS:
- Place colorful/vibrant content behind glass for best effect
- Use gradients as backgrounds to showcase the blur
- Maintain consistent blur values across your design
- Layer multiple glass elements for depth
- Combine with subtle animations for polish

TYPOGRAPHY:
- Use system fonts for authentic iOS feel:
  font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 
               'SF Pro Text', 'Helvetica Neue', sans-serif;
- Font weights: 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
- Letter spacing: -0.02em for headings, normal for body

SPACING & SIZING:
- Border radius: 12px (small), 16px (medium), 20px (large), 28px (XL)
- Padding: 16px, 20px, 24px, 32px
- Gap between glass elements: 12px - 24px
- Minimum touch target: 44x44px (iOS standard)

================================================================================
8. BROWSER COMPATIBILITY
================================================================================

backdrop-filter support:
- Chrome 76+ (full support)
- Firefox 103+ (full support)
- Safari 9+ (with -webkit- prefix)
- Edge 79+

For older browsers, provide fallback:
.glass {
    /* Fallback for browsers without backdrop-filter */
    background: rgba(255, 255, 255, 0.95);
}

@supports (backdrop-filter: blur(20px)) {
    .glass {
        background: rgba(255, 255, 255, 0.7);
        backdrop-filter: blur(20px);
    }
}
